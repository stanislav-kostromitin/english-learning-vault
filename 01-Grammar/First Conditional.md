# First Conditional

## Meaning

Use First Conditional for a real possible future situation and its likely result.

## Structure

```text
If + Present Simple, will + verb
If the build fails, we will investigate the logs.
```

## QA / Work Examples

- If the build fails, we will check the logs.
- If the fix works, we will deploy it to staging.
- If we find a blocker, we will raise it in stand-up.
- If the issue is reproducible, I will create a bug report.

## Contrast

Do not use `will` in the `if` part for normal First Conditional:

- Wrong: If the build will fail, we will check the logs.
- Better: If the build fails, we will check the logs.

## Common Mistakes

- Wrong: If the test will pass, we will merge the PR.
- Better: If the test passes, we will merge the PR.
- Reason: after `if`, use Present Simple for real future conditions.

## Practice

- Make one sentence about build failure.
- Make one sentence about deployment.
- Make one sentence about a blocker.

## Key Idea

For real future conditions: `if + Present Simple`, then `will`.
