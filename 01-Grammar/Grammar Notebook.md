# Grammar Notebook

This file contains grammar rules, examples, and personal conclusions from lessons.

## Core Principle

Do not choose English tenses by translating from Russian or by checking Jira task status. Choose the tense based on the meaning you want to communicate.

## Present Continuous

### Meaning

Use it when you describe what is happening right now.

### Structure

```text
am / is / are + verb-ing
```

### QA Examples

- I'm investigating this issue.
- I'm working on a report.
- We're testing the new API.

### Key Idea

Present Continuous is like a photo of the current moment.

## Present Perfect

### Meaning

Use it when the result is important now.

### Structure

```text
have / has + V3
```

### QA Examples

- I've fixed the bug.
- We've deployed the new version.
- I've written 20 automation tests.

### Key Idea

Present Perfect focuses on result, not on the exact time.

## Present Perfect Continuous

### Meaning

Use it when the activity started earlier and continues until now, or when the activity explains the current situation.

### Structure

```text
have / has + been + verb-ing
```

### QA Examples

- I've been investigating this issue since 9 a.m.
- We've been testing the API all morning.
- I've been working on the payment feature since yesterday.

### Key Idea

Present Perfect Continuous is like a video showing a period before now.

## Past Simple

### Meaning

Use it for completed events or completed time blocks in the past.

### Structure

```text
V2 / did + verb
```

### QA Examples

- I fixed the bug yesterday.
- I worked on the feature from 9 to 12.
- I had two meetings.

### Key Idea

Past Simple does not always mean the task is finished. It can mean only that the time block is finished.

## Important Comparison

### worked on ≠ finished

- I worked on the feature from 9 to 12.
  - Meaning: I spent time on it.
  - We do not know whether it is completed.

- I finished the feature at 12.
  - Meaning: the feature is completed.

## Personal Conclusions

- Do not choose the tense based on Jira status.
- Choose the tense based on what information the listener needs.
- A completed time block usually uses Past Simple.
- Current activity usually uses Present Continuous.
- Activity over a period up to now usually uses Present Perfect Continuous.
- Result now usually uses Present Perfect.
