# Prepositions for QA Communication

## Meaning

Prepositions often form fixed work phrases. Learn them as chunks, not as isolated rules.

## Structure

```text
in a meeting
on a call
at work
work on a feature
switch to a new branch
deploy to staging / production
issue in production
error in the logs
blocked by an issue
responsible for testing
```

## QA / Work Examples

- I am in a meeting.
- I am on a call with support.
- We are working on a new feature.
- The issue appears in production.
- I switched to a new branch.
- The deployment failed on staging.
- I found an error in the logs.

## Contrast

- in a meeting, but on a call.
- at work, but working on a task.
- deploy to an environment, but issue in an environment.

## Common Mistakes

- Wrong: I'm on a meeting.
- Better: I'm in a meeting.
- Reason: the fixed phrase is `in a meeting`.

- Wrong: I'm working in a feature.
- Better: I'm working on a feature.
- Reason: use `work on` for tasks/features.

- Wrong: The issue is on production.
- Better: The issue is in production.
- Reason: use `in production` for environment/location.

## Practice

- Say where you are: meeting/call/work.
- Say what task you are working on.
- Write one sentence about an issue in production and one about deployment to staging.

## Key Idea

Work prepositions are best learned as fixed phrases.
