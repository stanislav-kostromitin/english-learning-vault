# Present Continuous

## Meaning

Use Present Continuous when you show an action in progress now or a temporary situation around now. It is useful when the listener needs a "current activity" picture.

## Structure

```text
Positive: I am / you are / he is + verb-ing
Negative: I am not / you are not + verb-ing
Question: Are you + verb-ing?
```

## QA / Work Examples

- I'm investigating this issue.
- I'm working on a report.
- We're testing the new API.
- The team is checking the logs now.

## Contrast

- Present Simple: I test APIs every week. Focus: routine.
- Present Continuous: I am testing the API now. Focus: current temporary action.
- Present Perfect Continuous: I have been testing the API all morning. Focus: activity/duration until now.

## Common Mistakes

- Wrong: I am understand the issue.
- Better: I understand the issue.
- Reason: `understand` is usually a state verb, so use Present Simple.

- Wrong: I investigate this issue right now.
- Better: I am investigating this issue right now.
- Reason: `right now` points to an action in progress.

## Practice

- Say what you are working on today.
- Write a stand-up sentence about a task that is still in progress.
- Contrast: "I usually..." vs "Today I am..."

## Key Idea

Present Continuous is a photo of a current or temporary action.
