# Present Continuous

## Meaning

Use Present Continuous to describe what is happening now or around now.

## Structure

```text
am / is / are + verb-ing
```

## QA Examples

- I'm investigating this issue.
- I'm working on a report.
- We're testing the new API.

## Key Idea

Present Continuous is like a photo of the current moment.

## Compare

- What are you doing?
  - I'm working on a report.

- What have you been doing this afternoon?
  - I've been working on a report.

## Common Mistake

Short interruptions do not usually stop Present Continuous.

Example:

If you are working on a report and pause to answer a message, you can still say:

> I'm working on a report.
