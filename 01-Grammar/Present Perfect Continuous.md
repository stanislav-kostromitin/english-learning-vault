# Present Perfect Continuous

## Meaning

Use Present Perfect Continuous when the activity started earlier and continues until now, or when the activity explains the current situation.

## Structure

```text
have / has + been + verb-ing
```

## QA Examples

- I've been investigating this issue since 9 a.m.
- We've been testing the API all morning.
- I've been working on the payment feature since yesterday.

## Key Idea

Present Perfect Continuous is like a video showing a period before now.

## Important Nuance

Present Perfect Continuous does not always mean the action is unfinished.

It emphasizes:

- activity;
- duration;
- repeated effort;
- connection with now.

## Compare with Present Continuous

- I'm working on a report.
  - Focus: now.

- I've been working on a report all afternoon.
  - Focus: activity over a period until now.

## Common Mistake

Do not use Present Perfect Continuous for a completed time block.

Wrong:

> I have been writing automation tests from 9 a.m. to 11 a.m.

Better:

> I worked on automation tests from 9 a.m. to 11 a.m.
