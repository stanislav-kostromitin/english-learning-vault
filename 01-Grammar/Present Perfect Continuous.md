# Present Perfect Continuous

## Meaning

Use Present Perfect Continuous when an activity started earlier and continues until now, or when the activity explains the current situation. It focuses on activity, duration, repeated effort, or a visible recent process.

## Structure

```text
Positive: I have / she has + been + verb-ing
Negative: I have not / she has not + been + verb-ing
Question: Have you + been + verb-ing?
```

## QA / Work Examples

- I've been investigating this issue since 9 a.m.
- We've been testing the API all morning.
- I've been working on the payment feature since yesterday.
- The pipeline has been failing since the last deployment.

## Contrast

- I'm working on a report. Focus: now.
- I've been working on a report all afternoon. Focus: activity over time until now.
- I've written the report. Focus: completed result.
- I wrote the report from 9 to 11. Focus: finished past time block.

## Common Mistakes

- Wrong: I have been writing automation tests from 9 a.m. to 11 a.m.
- Better: I wrote automation tests from 9 a.m. to 11 a.m.
- Reason: `from 9 to 11` is a completed time block.

- Wrong: I've been investigation this bug.
- Better: I've been investigating this bug.
- Reason: after `have/has been`, use `verb-ing`.

## Practice

- Say what you have been working on today.
- Explain a current blocker using `I've been...`.
- Contrast a result sentence and an activity sentence.

## Key Idea

Present Perfect Continuous is a video of activity up to now.
