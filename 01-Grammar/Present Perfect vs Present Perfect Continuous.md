# Present Perfect vs Present Perfect Continuous

## Meaning

Use Present Perfect for a result, completed action, experience, or number. Use Present Perfect Continuous for activity, duration, repeated effort, or a recent visible process.

## Structure

```text
Present Perfect: have / has + V3
Present Perfect Continuous: have / has + been + verb-ing
```

## QA / Work Examples

- I have fixed the bug. Focus: result.
- I have been fixing the bug since morning. Focus: activity/duration.
- We have run 50 tests. Focus: number/result.
- We have been running tests all morning. Focus: activity.

## Contrast

- I've written the report. The report is probably complete or the result is important.
- I've been writing the report for two hours. The activity/duration is important.
- I've investigated three issues. Number/result.
- I've been investigating this issue since 10. Activity/duration.

## Common Mistakes

- Wrong: I have been fixed the bug.
- Better: I have fixed the bug.
- Reason: use Present Perfect for result; after `have been`, use `verb-ing`.

## Practice

- Say one result from today.
- Say one activity that has continued for some time.
- Explain the difference between `I've fixed` and `I've been fixing`.

## Key Idea

Ask: do I want to show the result or the activity/duration?
