# Present Perfect

## Meaning

Use Present Perfect when the result, fact, or experience is important now. The exact past time is not the main point.

## Structure

```text
Positive: I have / she has + V3
Negative: I have not / she has not + V3
Question: Have you + V3?
```

## QA / Work Examples

- I've fixed the bug.
- We've deployed the new version.
- I've written 20 automation tests.
- The team has verified the fix.

## Contrast

- I've fixed the bug. Focus: result now.
- I fixed the bug yesterday. Focus: when it happened.
- I've been fixing the bug for two hours. Focus: activity and duration.

## Common Mistakes

- Wrong: I have fixed the bug yesterday.
- Better: I fixed the bug yesterday.
- Reason: `yesterday` is a finished past time, so use Past Simple.

- Wrong: I have writed automation tests.
- Better: I have written automation tests.
- Reason: after `have/has`, use V3.

## Practice

- Say three work results using `I have...`.
- Convert: "I fixed it yesterday" vs "I have fixed it."
- Write one Jira update where the result matters now.

## Key Idea

Present Perfect connects a past action/result to now.
