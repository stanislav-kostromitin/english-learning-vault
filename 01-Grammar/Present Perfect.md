# Present Perfect

## Meaning

Use Present Perfect when the result, fact, or experience is important now.

## Structure

```text
have / has + V3
```

## QA Examples

- I've fixed the bug.
- We've deployed the new version.
- I've written 20 automation tests.

## Key Idea

Present Perfect focuses on result or fact, not on the exact time.

## Compare

- I've fixed the bug.
  - Focus: result now.

- I fixed the bug yesterday.
  - Focus: when it happened.

- I've been fixing the bug for two hours.
  - Focus: activity/duration.
