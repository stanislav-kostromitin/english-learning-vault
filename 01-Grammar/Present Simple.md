# Present Simple

## Meaning
Use Present Simple for facts, routines, habits, and permanent situations.

## Structure
- Positive: I work in QA.
- Negative: I do not / don't work on weekends.
- Question: Do you use this tool every day?

## QA Examples
- The team releases updates every Friday.
- We run regression tests before each release.
- The API returns 200 on success.

## Key Idea
Choose Present Simple for stable facts and regular routines.
