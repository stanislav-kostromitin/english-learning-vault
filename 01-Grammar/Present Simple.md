# Present Simple

## Meaning

Use Present Simple for facts, routines, habits, schedules, and stable situations. It tells the listener that something is generally true, not just happening now.

## Structure

```text
Positive: I work / she works
Negative: I do not work / she does not work
Question: Do you work? / Does she work?
```

## QA / Work Examples

- The team releases updates every Friday.
- We run regression tests before each release.
- The API returns 200 on success.
- I usually check logs after deployment.

## Contrast

- We run regression tests before each release. Focus: routine.
- We are running regression tests now. Focus: current action.

## Common Mistakes

- Wrong: The API return 200 on success.
- Better: The API returns 200 on success.
- Reason: with `he/she/it` or singular nouns, add `-s`.

## Practice

- Say three facts about your project.
- Say two routines from your workday.
- Contrast one routine with one current action.

## Key Idea

Present Simple is for stable facts and regular routines.
