# Quantifiers

## Meaning

Use quantifiers to describe amount or number: how much work, how many bugs, how few blockers, or how little information.

## Structure

```text
many + countable plural: many bugs, many tests
much + uncountable: much time, much information
a lot of + countable/uncountable: a lot of bugs, a lot of work
few + countable plural: few issues
little + uncountable: little time
```

## QA / Work Examples

- We found many bugs in regression.
- We do not have much time before release.
- There is a lot of work left.
- We have few blockers today.
- There is little information in the logs.

## Contrast

- many tests, not much tests.
- much time, not many time.
- a lot of works only if `works` means creations; for tasks, say `a lot of work`.

## Common Mistakes

- Wrong: We have many work.
- Better: We have a lot of work.
- Reason: `work` is usually uncountable.

- Wrong: We do not have many time.
- Better: We do not have much time.
- Reason: `time` is uncountable.

## Practice

- Say how many bugs were found.
- Say how much time is left.
- Say whether there are few or many blockers.

## Key Idea

Choose the quantifier by noun type: countable or uncountable.
