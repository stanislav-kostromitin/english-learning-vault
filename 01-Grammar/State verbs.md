# State verbs

## Meaning

State verbs describe states, feelings, beliefs, knowledge, possession, or perception. They usually describe what is true, not an action in progress.

## Structure

```text
I know / understand / believe / like / have / need
Usually not: I am knowing / I am understanding
```

## QA / Work Examples

- I know the root cause.
- I understand the current behavior.
- I believe the fix works.
- We need more logs to investigate this issue.

## Contrast

Some verbs can be state or action depending on meaning:

- I have access to production. State: possess/have.
- I am having a meeting. Action/event.
- I think the fix works. State: opinion.
- I am thinking about the root cause. Action: considering.

## Common Mistakes

- Wrong: I am knowing the reason.
- Better: I know the reason.
- Reason: `know` is a state verb.

- Wrong: I am understanding the bug.
- Better: I understand the bug.
- Reason: `understand` is a state verb.

## Practice

- Say what you know about the current issue.
- Say what you believe about the root cause.
- Make two sentences with `have`: one state, one event.

## Key Idea

State verbs usually use simple forms because they describe a state, not an action in progress.
