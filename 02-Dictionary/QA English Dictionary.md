# QA English Dictionary

A living vocabulary list for QA Automation and work communication.

## Status Legend

- 🟥 New
- 🟨 Learning
- 🟩 Mastered

## Single Words

Single-word status tracking lives in [[02-Dictionary/Vocabulary Index|Vocabulary Index]]
and in individual notes under `02-Dictionary/Words/`, not here - this avoided having two
disagreeing trackers for the same word (found during audit: this file had `deployment`
marked 🟥 New while Vocabulary Index had it 🟨 Learning after a later sync). This file
now focuses on QA-specific phrases and prepositions, which are not tracked elsewhere.

## Useful QA Phrases

| Phrase | Translation | Example | Status |
|---|---|---|---|
| work on a task | работать над задачей | I worked on a task this morning. | 🟨 |
| investigate an issue | расследовать проблему | I've been investigating this issue since 9 a.m. | 🟨 |
| fix a bug | исправить баг | I fixed a bug yesterday. | 🟨 |
| reproduce a bug | воспроизвести баг | I couldn't reproduce the bug. | 🟥 |
| write automation tests | писать автотесты | I've been writing automation tests all morning. | 🟨 |
| switch to another task | переключиться на другую задачу | I had to switch to another task. | 🟨 |
| task is still in progress | задача все еще в работе | The task is still in progress. | 🟨 |
| task is on hold | задача приостановлена | The automation task is on hold. | 🟥 |
| work on a report | работать над отчетом | I'm working on a report. | 🟨 |
