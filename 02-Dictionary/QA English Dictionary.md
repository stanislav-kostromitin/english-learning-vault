|---|---|---|---|
| feature | фича, функциональность | I'm working on a new feature. | 🟨 |

| bug | баг | I fixed the bug yesterday. | 🟨 |
| production | продакшн | We found a production issue. | 🟨 |

| Phrase | Translation | Example | Status |
|---|---|---|---|
