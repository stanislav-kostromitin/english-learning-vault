# feature

Status: 🟨 Learning

## Translation

фича, функциональность

## Meaning

A part or function of a product or system.

## Examples

- I'm working on a new feature.
- We need to test this feature before release.
- The payment feature is still in progress.

## Common Mistakes

Do not confuse:

- feature = фича
- feather = перо
- future = будущее
