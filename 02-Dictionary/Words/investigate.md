# investigate

Status: 🟨 Learning

## Translation

расследовать, изучать проблему

## Meaning

To examine a problem carefully to understand the cause.

## Examples

- I'm investigating this issue.
- I've been investigating the bug since 9 a.m.
- We need to investigate why the API returns 500 errors.
