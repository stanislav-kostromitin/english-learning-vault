# QA English Cheat Sheet

Ready-to-use phrases for work communication.

## Main Tense Choice Reminder

Do not choose tense based on Jira status.

Choose tense based on what you want to communicate.

| Meaning | Better tense | Example |
|---|---|---|
| completed time block | Past Simple | I worked on automation tests from 9 to 11. |
| completed action with current result | Present Perfect | I've fixed the bug. |
| activity / duration / visible process | Present Perfect Continuous | I've been investigating this issue all morning. |
| action happening now / temporary situation | Present Continuous | I'm working on a new feature. |
| routine / fact | Present Simple | I usually join the daily meeting at 9. |

Important:

```text
I worked on the task.
```

This does not mean:

```text
I finished the task.
```

It only means you spent time on it.

## Daily Stand-up

### Current work

- I'm currently working on a new feature.
- I'm investigating a production issue.
- I'm working on a report right now.
- I'm checking the API response.
- I'm reviewing test results.

### Work over a period

- I've been working on this task since 9 a.m.
- I've been investigating this issue all morning.
- I've been testing the API since this morning.
- I've been reviewing failed tests for the last hour.

### Completed work

- I've completed the task.
- I've fixed the bug.
- I've written 20 automation tests.
- We have deployed the new version.
- I've verified the fix on staging.

### Completed time blocks

- I worked on automation tests this morning.
- I had two meetings.
- I investigated a bug after lunch.
- I reviewed failed tests from 9 to 10.

### Switching context

- I had to switch to a production bug.
- I had to pause the automation task.
- The feature is still in progress.
- The task is currently on hold.
- I was blocked by an environment issue.

## Bug Discussion

- I can reproduce it.
- I couldn't reproduce it.
- The issue is intermittent.
- The issue happens only on staging.
- We need to check whether the API returns the correct response.
- I found the cause of the problem.
- We need to identify the root cause.
- I verified the fix in the test environment.
- The workaround works, but we still need a proper fix.

## Meetings

- Could you repeat that?
- Could you clarify that?
- I agree.
- I don't fully agree.
- From my point of view, this behavior looks incorrect.
- Let me check and get back to you.
- I need a bit more context.
- Could you give me an example?

## Interview

- In my previous project, I was responsible for test automation.
- I worked with Java, REST Assured, Selenium, Playwright, and CI/CD pipelines.
- I created automated tests for regression and integration testing.
- I analyzed requirements and prepared test cases.
- I investigated failed tests and reported defects.
- I worked closely with developers and product owners.
