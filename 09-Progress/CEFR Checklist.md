# CEFR Can-Do чек-лист

Источник: официальная self-assessment grid Совета Европы (CEFR), адаптирована в
чек-лист. Формулировки ниже - пересказ своими словами, не дословная цитата
оригинального документа. Точные официальные формулировки - на
coe.int/en/web/common-european-framework-reference-languages, более детальный набор
дескрипторов - в CEFR Companion Volume (2020) там же. Периодическая внешняя сверка
результата - efset.org (бесплатно, выровнен по CEFR) - см. `COURSE_RULES.md`,
"External Calibration".

Дополняет, а не заменяет таблицу `% confidence` в `Progress Tracker.md` - там
отслеживаются отдельные грамматические темы, здесь - владение языком в целом по
пяти видам активности. Ставить галочку следует только на основании накопленных
эпизодов из `05-Lessons/`, а не по разовому удачному ответу.

## A2 (Waystage, базовый - предполагается пройденным, отметить фактическое состояние)

### Аудирование
- [ ] Понимает фразы и частотную лексику на темы личной значимости (работа, покупки,
      район проживания)
- [ ] Улавливает суть коротких, чётких объявлений и сообщений

### Чтение
- [ ] Понимает короткие простые тексты, объявления, письма

### Устное взаимодействие
- [ ] Справляется с простыми повседневными задачами (обмен информацией на знакомые
      темы)

### Устное высказывание
- [ ] Может простыми фразами описать своё окружение, повседневные дела

### Письмо
- [ ] Может написать короткие простые заметки и сообщения

## B1 (Threshold - целевой уровень для текущего этапа курса)

### Аудирование
- [ ] Понимает основную мысль ясной стандартной речи на знакомые рабочие/бытовые темы
- [ ] Понимает основные моменты в материалах на знакомую тематику при относительно
      медленной, чёткой речи

### Чтение
- [ ] Понимает тексты на частотной повседневной/рабочей лексике
- [ ] Понимает описание событий и мнений в переписке (Slack/Jira-комментарии,
      письма)

### Устное взаимодействие
- [ ] Может без подготовки участвовать в разговоре на знакомые рабочие темы
      (Daily Stand-up, обсуждение бага)
- [ ] Справляется в большинстве стандартных рабочих ситуаций

### Устное высказывание
- [ ] Может связно рассказать о задаче, инциденте, плане действий
- [ ] Может кратко обосновать своё мнение или объяснить причину проблемы

### Письмо
- [ ] Может написать связный текст на знакомую рабочую тему (Jira-комментарий, отчёт)
- [ ] Может описать инцидент или процесс в письменном виде

## Как заполняется

Дескриптор отмечается выполненным на основании накопленных подтверждающих эпизодов
в `05-Lessons/` (минимум 3, в разных уроках, не подряд в одном) - не по разовому
ответу и не "на глаз". Пока отдельного skill'а `progress-review` для автоматизации
этого нет (см. `Skills-Outline.md`) - обновляется вручную при синхронизации Vault.

B2/C1-разделы добавить сюда же, когда курс реально приблизится к этому уровню - не
заполнять заранее.
