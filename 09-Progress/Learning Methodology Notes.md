# Learning Methodology Notes

Last updated: 2026-07-04

This file summarizes the methodology used in the English Learning Vault.

## Practical Direction

The course should not become a grammar encyclopedia. It should train usable English for:

- QA Automation work;
- technical meetings;
- bug discussions;
- interviews;
- demos;
- production incidents;
- written Jira / Slack communication.

## Methodological Principles

### 1. Comprehensible Input

The learner needs regular English input that is understandable but slightly above the current level.

Implementation:

- short reading texts at A2/B1/B2 level;
- listening with transcript;
- QA-related dialogs;
- repeated exposure to the same grammar in different contexts.

### 2. Meaning-Focused Output

The learner must produce language, not only consume it.

Implementation:

- Daily stand-up simulations;
- bug explanations;
- interview answers;
- short written reports;
- role-play with correction.

### 3. Focus on Form in Context

Grammar should be corrected inside real communication, not as isolated tables only.

Implementation:

- first express the idea;
- then correct the grammar;
- then repeat the corrected sentence;
- then reuse it in a new work situation.

### 4. Spaced Repetition and Active Recall

Review should happen after delays, not only immediately after explanation.

Implementation:

- return to weak topics after several lessons;
- ask the learner to produce sentences without hints;
- track topics as Learn → Recall → Production → Automation.

### 5. Fluency Development

The learner must practice familiar language until it becomes fast and automatic.

Implementation:

- repeat common work scenarios;
- use time pressure;
- reduce Russian support gradually;
- reuse phrases until they become automatic.

### 6. Corrective Feedback

Feedback should explain the thinking error, not only the grammar error.

Implementation:

- wrong sentence;
- natural version;
- reason;
- thinking pattern;
- repeat task.

## Current Course Adjustments

The course should now emphasize:

1. More speaking production.
2. More spaced recall.
3. More QA / IT scenarios.
4. Less isolated grammar drilling.
5. More tracking of personal recurring errors.
6. More collocations and sentence patterns.

## Sources / Concepts Used

These ideas are based on established second language acquisition and learning-science concepts:

- Paul Nation's Four Strands: meaning-focused input, meaning-focused output, language-focused learning, and fluency development.
- Krashen's comprehensible input hypothesis.
- Long's interaction hypothesis and negotiation of meaning.
- Focus on Form: grammar attention inside communication.
- Spaced repetition and forgetting-curve based review.
- Active recall / retrieval practice.

## Course Rule

The course plan is not fixed. If the learner's repeated mistakes show that another sequence would be more efficient, the plan should be changed.
