# Итоговый отчёт: сведение 4 проектов в один

Дата: 2026-07-08. Автор: Claude, по запросу на анализ + консилиум + финальный проект.

## 1. Что анализировалось

Загружено 4 архива, претендующих на одну и ту же систему:

1. `english-learning-project.zip` - чистая реализация архитектурного документа
   `language-learning-architect-v1`: пустой vault, но с рабочим синтаксисом Templater/
   Dataview/Spaced Repetition и пошаговым SETUP с проверками на каждом шаге.
2. `english-learning-vault.zip` - мой первый черновик архитектуры (CLAUDE.md,
   Skills-Outline с разделением policy/guidance, generic CEFR-чеклист). Без реальных
   данных, без рабочего синтаксиса плагинов.
3. `english-learning-vault-merged.zip` - результат мерджа архитектуры (2) в реальный
   репозиторий пользователя. Содержал баг упаковки (дублирующая вложенная папка) -
   на факт слияния это не повлияло, но зафиксировано как известная проблема прошлой
   поставки.
4. `my-english-learning-vault-git.rar` - **фактическое текущее состояние** репозитория
   `stanislav-kostromitin/english-learning-vault` с полной git-историей и папкой
   `.obsidian`: 6 реальных уроков, детальный Progress Tracker (A2→B1, % уверенности по
   темам), Mistake Journal, QA-словарь. Плагины Templater/Dataview/Spaced Repetition/
   Obsidian Git уже установлены и настроены. Дополнительно обнаружены два плагина, не
   упомянутые ни в одном архитектурном документе: **Agent Client** (ACP-мост,
   позволяет вести чат с Claude Code прямо во вкладке Obsidian) и **AI for Templater**.

## 4. Как это работает сейчас (весь цикл)

1. **Активное занятие** - открыть Obsidian → команда "Agent Client: Open chat" →
   Claude Code внутри vault читает `CLAUDE.md` → `CLAUDE.md` отправляет к
   `COURSE_RULES.md` за методологией и к `Progress Tracker.md` за текущим фокусом.
2. Новые слова/правила создаются через шаблоны в `10-Templates/` → сразу с карточкой
   для повторения.
3. После занятия - изменения коммитятся (вручную или через Obsidian Git).
4. **Пассивное повторение** - в любой момент, на телефоне, офлайн, через встроенную
   очередь плагина Spaced Repetition - AI для этого не нужен.
5. **Обзор прогресса** - `09-Progress/Dashboard.md` (что видно через Dataview прямо
   сейчас) + `09-Progress/Progress Tracker.md` (детальная ручная таблица по темам,
   остаётся основной для грамматики) + `09-Progress/CEFR Checklist.md` (владение
   языком в целом, по официальным дескрипторам).

## 5. План дальнейшего развития

Не всё нужно делать сразу - порядок важен:

1. **Сейчас:** проверить весь цикл руками по чек-листам в `SETUP.md` (шаги 1-4) -
   без этого дальнейшая разработка идёт вслепую.
2. **Когда написание новых заметок через шаблоны станет привычкой:** оценить, стоит
   ли дать грамматическим заметкам frontmatter аналогично словарю - но только если
   реально понадобится Dataview-запрос по грамматике, а не для симметрии.
3. **Когда Mistake Journal станет неудобно читать целиком** (сейчас - нет): перейти
   на одну заметку на ошибку, как предлагал Архитектор систем. Признак, что пора -
   не число записей, а то, что реально хочется отфильтровать/отсортировать список
   и один файл этого не даёт.
4. **Skills по `Skills-Outline.md`** - писать по одному, тестировать через
   `skill-creator`, только когда `CLAUDE.md` + `COURSE_RULES.md` одним файлом
   станут действительно неудобны (сейчас - ещё нет, дробить рано).
5. **CEFR Checklist** - заполнять по мере накопления эпизодов в `05-Lessons/`, не
   заранее. Раздел B2/C1 добавить в файл, когда курс реально приблизится к этому
   уровню.
6. **Мобильный доступ** - протестировать шаг 4 из `SETUP.md` при первой поездке без
   компьютера - это единственная надёжная проверка.

## 6. Известные ограничения (честно, не скрыто)

- Dashboard не может сейчас показать сводку по грамматике и ошибкам через Dataview -
  только по словарю. Это сознательное решение (раздел 3 отчёта), не недосмотр.
- Agent Client - десктопный плагин, на телефоне не работает - для мобильного активного
  занятия по-прежнему нужно мобильное приложение Claude + Claude Code на десктопе.
- Формат карточек Templater/Spaced Repetition проверялся по документации на момент
  анализа (см. `SETUP.md`) - при использовании стоит свериться, что синтаксис не
  изменился в новых версиях плагинов.
