## Что изменилось в архитектуре по итогам сравнения

1. **Skills переведены в официальный формат.** `anthropics/skills` показывает, что
   правильный формат - `<skill-name>/SKILL.md` с `name`/`description` во frontmatter,
   в директории, которую агент сканирует автоматически (`.claude/skills/`), а не один
   описательный файл `Skills-Outline.md`. Написаны 3 реальных скилла (см. ниже) -
   именно те, что нужны для "агент как движущая сила", а не все 8 из старого outline
   сразу - выбраны по критерию "нужны для автономной работы агента прямо сейчас".

2. **Появился vault-maintainer.** Ни в одном из моих прошлых проходов не было
   механизма самоочистки. `obsidian-wiki`'s `wiki-lint --consolidate` - прямой
   прецедент для этого паттерна (dry-run diff + подтверждение перед записью - важно,
   не давать агенту молча тереть/переписывать данные ученика).

3. **Появилась внешняя калибровка (EF SET).** Раньше единственный источник "какой
   у меня реально уровень" - собственные оценки агента (% в Progress Tracker) и
   ручной CEFR-чеклист. Это может расходиться с реальностью в обе стороны (агент
   может как переоценивать, так и недооценивать). EF SET - независимая точка сверки.
