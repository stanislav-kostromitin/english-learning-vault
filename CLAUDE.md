## 0. РАЗДЕЛЕНИЕ СЛОЁВ

1. **Vault (этот Obsidian-репозиторий)** - устойчивые знания и элементы для запоминания:
   `01-Grammar/`, `02-Dictionary/`, `03-Mistakes/`, `09-Progress/`. Единственное
   хранилище состояния - НЕ история чата.
2. **Плагин Spaced Repetition (FSRS) внутри Obsidian** - расписание повторений.
   Плагин установлен и настроен (сепаратор карточек `::`, см. `SETUP.md`). Карточки
   уже есть в шаблонах `10-Templates/Grammar Note Template.md` и
   `10-Templates/Vocabulary Word Template.md` - используй их для новых заметок.
   Старые заметки в `01-Grammar/`/`02-Dictionary/` карточек пока не содержат -
   не обязательно, добавляй по мере того, как тема реально в активной ротации.
3. **Сессия** - практика: говорение, письмо, QA-кейсы, живые исправления. Результат
   сессии persist-ится в Vault. Сам чат/сессия одноразовые.
   Основной способ вести активное занятие - плагин **Agent Client** (уже установлен,
   ACP-мост к Claude Code прямо во вкладке Obsidian, см. раздел 1а) вместо отдельного
   терминала. Уроки через ChatGPT (см. README.md, "Working Process") по-прежнему
   допустимы - ничего не ломается, если продолжать так же.

## 1. ДВА РЕЖИМА СЕССИИ

| Режим | Что это | Нужен ли AI | Где происходит |
|---|---|---|---|
| **Активное занятие** | Ввод нового материала, исправления, письмо, говорение | Да | Плагин Agent Client в Obsidian (см. 1а), или Claude Code в терминале, или мобильное приложение Claude |
| **Пассивное повторение** | Карточки по уже введённому материалу | Нет | Obsidian mobile, плагин Spaced Repetition, офлайн |

### 1а. Agent Client - основной способ вести занятие

В vault уже установлен плагин **Agent Client** (ACP - Agent Client Protocol). Он
запускает Claude Code прямо во вкладке Obsidian - не нужно переключаться в терминал,
агент сразу видит открытую заметку и имеет файловый доступ к vault. Это снимает
компромисс "телефон vs десктоп vs терминал", который обсуждался в архитектурных
документах ранее - Agent Client уже отвечает на этот вопрос практически.

Использование: команда "Agent Client: Open chat" из палитры команд Obsidian, выбрать
агента Claude Code. Требует установленного Claude Code CLI и ACP-адаптера - если ещё
не настроено, см. `SETUP.md`.

Claude Code в отдельном терминале и мобильное приложение Claude остаются рабочими
альтернативами - Agent Client не единственный путь, просто самый прямой.

## 3а. АГЕНТ КАК ДВИЖУЩАЯ СИЛА - фокус, инициатива, самообслуживание

Это прямое требование к поведению агента (не просто рекомендация):

- **Держать фокус занятия.** Не уходить далеко от заявленной темы урока без явного
  решения (не молчаливого дрейфа). Подробный протокол - skill `session-focus-guard`,
  использовать в каждом активном занятии, не только когда что-то пошло не так.
- **Не повторяться без необходимости.** Не объяснять то же правило второй раз в
  рамках одной сессии, если оно уже отработано - см. `session-focus-guard`.
- **Быть инициатором, а не только отвечать.** После каждого блока занятия -
  предлагать следующий шаг самостоятельно (из Progress Tracker), не дожидаться
  вопроса "что дальше". Готовить материал для следующего урока заранее - skill
  `content-preparation`, не создавать заметки на лету под давлением времени занятия.
- **Следить за чистотой и актуальностью vault.** Периодически (раз в 5-10 занятий,
  или по запросу) - skill `vault-maintainer`: битые ссылки, дубликаты заметок,
  противоречащие статусы, рассинхронизация нумерации. Никогда не удалять данные
  реального прогресса (историю повторений SR-карточек) при слиянии дубликатов -
  подробности в самом skill'е.

Доступные skills - в `.claude/skills/`:
- `session-focus-guard` - фокус и инициатива внутри занятия
- `content-preparation` - подготовка материала вперёд
- `vault-maintainer` - самообслуживание и чистота vault

Формат skill-файлов соответствует официальному стандарту Anthropic
(`name`/`description` в frontmatter + инструкции, см. `00-Meta/ARCHITECTURE-REVIEW.md`,
пункт 1) - агент подхватывает их автоматически по описанию, не нужно вызывать вручную
по имени, если сама ситуация уже описана в `description`.

## 4. POLICY VS GUIDANCE (новое - в COURSE_RULES.md этого разделения не было)

Системный промпт - инструкция, которую модель читает, а не гарантия поведения. Это не
моё предположение - это прямая формулировка Anthropic: инструкции в CLAUDE.md
соблюдаются моделью не всегда (по их собственным данным - около 70% случаев), а
`.claude/settings.json` hooks - на уровне инструмента, детерминированно. Поэтому там,
где это технически возможно, policy закрепляется хуком, а не только текстом ниже.

- **Policy, закреплено хуком (не только текстом):**
  - Нельзя создать новую заметку в `01-Grammar/` или `02-Dictionary/Words/` с именем,
    похожим на уже существующее (`bug` vs `bug1` и т.п.) - блокируется
    `.claude/hooks/check-duplicate-note.ps1` через PreToolUse, реальная причина -
    именно так один раз чуть не потеряли историю FSRS-повторений (см.
    `00-Meta/ARCHITECTURE-REVIEW.md`, журнал проверок). Хук проверяет это на каждой попытке
    записи, не полагаясь на то, что агент "не забудет".
- **Policy, пока только текстом (кандидаты на будущий хук, если ошибка повторится):**
  - Тема не помечается "Automation" только по ощущению - нужен критерий:
    использование под давлением времени/в разговоре без подготовки (уже описано в
    `COURSE_RULES.md`, Stage 4) - агент не присваивает эту стадию сам, только
    фиксирует, когда пользователь это продемонстрировал.
  - Ошибка не помечается `resolved` без того, чтобы она не появлялась несколько
    уроков подряд (уже есть в `COURSE_RULES.md`, "Error Knowledge Base").
  - После установки плагина Spaced Repetition - расписание повторений считает
    плагин (FSRS), агент не придумывает своё.
- **Guidance (гибкость, остаётся текстом):**
  - Как сформулировать пример под конкретную QA-ситуацию.
  - Тон коррекции (см. "Correction Style" в `COURSE_RULES.md`).

## 5. МОБИЛЬНЫЙ ДОСТУП (новое)

Текущий репозиторий не был явно спроектирован под телефон. Если нужен доступ с
телефона:
- Пассивное повторение - через Obsidian mobile + плагин Spaced Repetition, офлайн.
- Активное занятие с телефона - через мобильное приложение Claude, подключённое к
  Claude Code, который работает на десктопе/сервере.
- Синхронизация Vault между устройствами - git (уже используется) или Obsidian Sync.
