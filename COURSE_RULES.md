# Course Rules

This file defines how the English learning project is maintained.

## Main Goal

Build practical English skills for QA Automation, technical communication, meetings, interviews, and daily work.

Target path:

```text
A2 → B1 → B2 → C1
```

## Core Principles

1. Do not learn grammar as isolated formulas.
2. Learn grammar through real work situations.
3. Do not move too fast. A topic is continued until it becomes usable.
4. New vocabulary is added to the dictionary and reused in later lessons.
5. Repeated mistakes are stored in the Mistake Journal.
6. Every lesson should include practice, not only theory.
7. Reading and listening should reinforce the current grammar and vocabulary.
8. The repository is the main source of truth. The chat is used for practice and explanations.

## Lesson Structure

Each lesson should usually include:

1. Short review
2. Grammar or vocabulary focus
3. Real QA / work examples
4. Practice
5. Error correction
6. Repository update
7. Mini homework or review task

## Correction Style

Corrections should explain:

- what is wrong;
- why it is wrong;
- how to say it naturally;
- what thinking pattern caused the mistake.

## Repository Maintenance Rules

After a lesson, update relevant files:

- Grammar pages
- Vocabulary pages
- Mistake Journal
- Cheat Sheet
- Lesson notes
- Progress Tracker
- Homework / Reading / Listening if needed

## Current Learning Strategy

Focus on understanding meaning and context before memorizing rules.

Important recurring principle:

> Do not choose the tense based on the Jira status. Choose the tense based on what information the listener needs.
