## Working Process

1. Before a lesson, pull updates.

```bash
git pull
```

2. Use ChatGPT for the lesson and speaking/writing practice.
3. After the lesson, ChatGPT updates this repository.
4. Pull again to see updated grammar notes, vocabulary, mistakes, reading, listening, and homework.

## Main Rule

Do not learn grammar as isolated formulas. Learn how native speakers choose tense based on meaning, context, and what the listener wants to know.
