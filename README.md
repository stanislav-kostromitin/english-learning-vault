## How to Use

1. Clone this repository.
2. Open it in VS Code, IntelliJ IDEA, or Obsidian.
3. During lessons, ChatGPT will update Markdown files directly in this repository.
4. Pull changes before each lesson.

```bash
git pull
```

## Rule of the Course

Do not learn grammar as isolated formulas. Learn how native speakers choose tense based on meaning, context, and what the listener wants to know.
