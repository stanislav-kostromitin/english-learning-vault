# Установка и запуск (актуальное состояние + что добавить)

Этот файл описывает, что уже настроено в репозитории, и оставшиеся шаги. Проверяй
каждый шаг перед тем, как переходить к следующему.

## Уже сделано (проверять, не переустанавливать)

- Vault открыт в Obsidian, репозиторий синхронизирован через git.
- Плагины установлены и включены: **Templater**, **Dataview**, **Spaced Repetition**,
  **Obsidian Git**, **AI for Templater**, **Agent Client**.
- Spaced Repetition: сепаратор одиночной карточки - `::` (по умолчанию, соответствует
  шаблонам в `10-Templates/`).
- **Алгоритм FSRS подтверждён активным** (аудит от 2026-07-09): реальные карточки
  в `01-Grammar/` и `02-Dictionary/Words/` содержат `<!--SR:!fsrs,...-->` - переключать
  вручную больше не нужно, это уже было сделано раньше.

Проверка: Settings → Community plugins - все шесть должны быть в списке и включены.

## Шаг 1. Проверить карточки на новой заметке

1. В `02-Dictionary/Words/` создай новую заметку, примени шаблон
   `10-Templates/Vocabulary Word Template.md` через Templater
   (`Ctrl/Cmd+P` → "Templater: Open insert template modal").
2. Заполни `::` строку внизу реальной фразой.
3. Сохрани, открой панель Spaced Repetition (иконка в левой ленте) - карточка должна
   появиться в очереди на сегодня.

Если карточка не появилась - проверь, что строка отформатирована ровно как
`Текст::Текст`, без пробелов вокруг `::`.

## Шаг 2. Проверить Dashboard

Открой `09-Progress/Dashboard.md`. Таблица "Словарь по статусу" должна показать
существующие 4 слова (bug, feature, investigate, issue) со статусом `learning` - это
подтверждает, что Dataview видит frontmatter. Если видишь текст ошибки вида
"Dataview: ..." - плагин Dataview выключен, включить в Settings → Community plugins.

## Шаг 3. Настроить Agent Client (активные занятия без терминала)

Плагин уже установлен, но требует Claude Code CLI и ACP-адаптер отдельно:

```bash
curl -fsSL https://claude.ai/install.sh | bash
npm install -g @agentclientprotocol/claude-agent-acp
```

Сверься с `docs.claude.com` на актуальный способ установки Claude Code - команда
могла измениться.

В Obsidian: команда "Agent Client: Open chat" из палитры (`Ctrl/Cmd+P`) → выбрать
Claude Code как агента → пройти авторизацию через аккаунт Anthropic (плагин запросит
при первом запуске).

**Проверка:** спроси в чате Agent Client "прочитай Progress Tracker и скажи, какая
тема сейчас в фокусе" - если ответ ссылается на реальные темы из файла (Present
Perfect Continuous, State verbs и т.д.), а не общие рассуждения - агент действительно
видит vault.

## Шаг 4. Мобильный доступ

- Пассивное повторение: Obsidian mobile + синхронизация (git через Obsidian Git,
  либо Obsidian Sync) → плагин Spaced Repetition работает офлайн на телефоне.
- Активное занятие с телефона: мобильное приложение Claude, подключённое к Claude
  Code, который работает на десктопе (Agent Client - десктопный плагин, на телефоне
  недоступен - это ограничение плагина, не обход).

**Проверка:** создай тестовую карточку на компьютере → дождись синхронизации →
открой очередь повторения в Obsidian mobile - карточка должна быть доступна офлайн
(проверить в самолётном режиме).

## Шаг 5. Дальше - обычный курс

Продолжать по `COURSE_RULES.md` и текущему чекпоинту в `05-Lessons/Lessons Index.md`.
Новые грамматические/словарные заметки - через шаблоны из `10-Templates/`, чтобы
карточки создавались сразу, без ретроактивной доработки.

## Если что-то не работает

- Dataview показывает ошибку - плагин выключен.
- Templater не подставляет `<% tp.date.now(...) %>` - шаблон открыт напрямую, а не
  вставлен через команду Templater, либо не настроена Template folder location
  (Settings → Templater → Template folder location → `10-Templates`).
- Карточка не появляется в очереди - проверить формат `Текст::Текст`.
- Agent Client не видит контекст - убедиться, что чат открыт из папки репозитория
  (рабочая директория ACP-сессии = vault), и что `CLAUDE.md` лежит в корне.
- Синхронизация на телефон не долетает - на git-варианте синхронизация не
  автоматическая, нажимать кнопку синхронизации Obsidian Git на каждом устройстве.
