# Установка нового слоя (Obsidian-плагины + Claude Code)

Этот репозиторий уже работает как markdown-vault с реальной историей уроков. Ниже -
как добавить недостающую часть (реальный spaced repetition + доступ с телефона +
Claude Code), не ломая то, что уже накоплено.

## Шаг 1. Открыть репозиторий как Obsidian vault

1. Установи Obsidian (obsidian.md), если ещё нет.
2. Open folder as vault → выбрать папку с этим репозиторием (`english-learning-vault`).
   Все существующие заметки и wikilinks (`[[...]]`) заработают как есть.

## Шаг 2. Установить плагины

Settings → Community plugins → Browse:

- **Spaced Repetition** - для реального интервального повторения (FSRS). Сейчас
  прогресс отслеживается вручную (🟩/🟨/🟥 в Progress Tracker) - плагин не заменяет
  эту таблицу, а добавляет слой автоматических повторений поверх заметок в
  `01-Grammar/` и `02-Dictionary/`.
- **Dataview** - запросы по репозиторию (due-карточки, открытые ошибки).
- **Templater** - подстановка `10-Templates/Lesson Template.md` при создании нового
  урока.

Проверь синтаксис карточек и настройки алгоритма в актуальной документации плагина -
он периодически меняется.

### Как добавлять карточки в новые заметки

В конец новой заметки в `01-Grammar/` или `02-Dictionary/` добавляй пары вида:

```text
Вопрос на английском?::Ответ
```

Старые заметки ретроактивно переделывать не обязательно - добавляй карточки
постепенно, по мере того как тема реально попадает в активную ротацию.

## Шаг 3. Синхронизация на телефон

Репозиторий уже на git - это уже рабочий вариант синхронизации. Дополнительно:

- Установи Obsidian mobile, открой тот же vault через git-клиент для мобильного
  (например, плагин Obsidian Git) или через Obsidian Sync (платно, проще).
- Включи Spaced Repetition и Dataview в мобильной версии.
- Проверь: пассивное повторение должно работать офлайн, без AI.

## Шаг 4. Установить Claude Code (опционально, параллельно с ChatGPT-процессом)

```bash
npm install -g @anthropic-ai/claude-code
```

Сверься с docs.claude.com на актуальные требования перед установкой.

```bash
cd english-learning-vault
claude
```

Claude Code подхватит `CLAUDE.md` из корня. `CLAUDE.md` ссылается на `COURSE_RULES.md`
как на основной источник методологии - переписывать `COURSE_RULES.md` не нужно.

Для активного занятия с телефона - через мобильное приложение Claude, подключённое к
Claude Code на десктопе/сервере (не нужно ничего ставить на телефон отдельно для
этого режима).

## Шаг 5. Продолжить курс

В Claude Code:

```
Прочитай Progress Tracker и Course Rules, продолжи курс с текущего чекпоинта
(Lesson 06 - Chat Cleanup Checkpoint).
```

После занятия - обычный git commit/push, как описано в "Vault Synchronization
Protocol" в `COURSE_RULES.md`.

## Что осталось без изменений

- Можно продолжать вести уроки через ChatGPT, как раньше - CLAUDE.md ничего не
  ломает и не требует немедленного перехода. Claude Code - альтернативный, не
  обязательный путь.
- Вся структура папок, `COURSE_RULES.md`, история уроков и прогресс - без изменений.
